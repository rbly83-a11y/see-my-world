# SEE MY WORLD

A privacy-first Perspective Network: a personal World you correct into truth
(testimony, never inference), shared only as bounded, owner-authorized
Perspectives, and explored by visitors without surveillance.

**Founder and final product authority:** Robert Edward Bly.
**Baseline of record:** Product Bible **Edition 1.4** (21 November 2026).

## The one distinction this repository never blurs

- **The product is greenfield.** No SEE MY WORLD product code exists yet.
  Everything the Bible describes is specification — Concept or Specified,
  never silently "Implemented."
- **WORLD FORGE is real.** The AI development factory that will build the
  product exists as a working, locally tested prototype in `world-forge/`.

Current status, in the project's three tiers — *implemented*, *passed
automated tests*, *verified against a live runtime* — is maintained in
[docs/verification/DEVELOPMENT-STATUS.md](docs/verification/DEVELOPMENT-STATUS.md).

## Working rules (from the Product Bible and the Universal AI Agent Contract)

- Testimony-v1 is frozen. Founder decisions are never resolved by agents.
- A feature's status label must be earned with evidence: Concept, Specified,
  Implemented, Tested, Pilot Validated, Production Ready.
- Payments never imply permissions; school activity never enters consumer
  profiles; a private memory's existence is never disclosed — not by search,
  counts, errors, recommendations, or caches.
- Evidence, testimony, reconstruction, and fiction are kept distinct,
  everywhere, always.
